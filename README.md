# manchas-noise-monitor

Classroom noise monitor featuring Manchas, the Jaguar.

## Running locally

```
./serve.sh
```

This serves the app at http://localhost:8000 and opens it in your browser. Pass a port to use a different one (`./serve.sh 3000`). Serving it, rather than opening `index.html` directly, lets the 3D classroom load its chalkboard texture.
